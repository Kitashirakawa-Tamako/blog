# 服务器

## 腾讯云

本站部署于 [京东云](https://www.jdcloud.com/) 轻量云主机，规格： CPU - 2核 内存 - 4GB；使用 [FinalShell](http://www.hostbuf.com/t/988.html) 作为ssh连接工具。

# 前后台通用

## React

[React](https://react.docschina.org/) 用于构建 Web 和原生交互界面的库。

## Axios

[Axios](http://www.axios-js.com/zh-cn/docs/) 是一个基于 promise 的 HTTP 库，可以用在浏览器和 node.js 中。

## Ant Design of React

[antd](https://ant.design/index-cn) 是基于 Ant Design 设计体系的 React UI 组件库，主要用于研发企业级中后台产品。

# 前台

## Next.js

[Next.js](https://nextjs.org/) 是一个轻量级的 React 服务端渲染应用框架。

## 高德Web服务API

使用 [高德Web服务API](https://lbs.amap.com/api/webservice/summary) 处理访客IP、天气等信息。

# 后台

## Ant Design Pro

[Ant Design Pro](https://pro.ant.design/zh-CN) 是基于 [Ant Design](https://ant.design/index-cn) 和 [umi](https://umijs.org/) 的封装的一整套企业级中后台前端/设计解决方案。

## pnpm

[pnpm](https://www.pnpm.cn/)- 速度快、节省磁盘空间的软件包管理器，比npm速度更快！体积更小！更稳定！

## react-markdown-editor-lite

[react-markdown-editor-lite](https://github.com/HarryChen0506/react-markdown-editor-lite) 是一款轻量的基于React的markdown编辑器。对比其他React markdown编辑器来说，更美观简洁易用！

## Nginx

[Nginx](http://nginx.org/en/index.html) (engine x) 是一个高性能的HTTP和反向代理web服务器

# 后端

## Spring Cloud Alibaba

使用 [Nacos](https://nacos.io/zh-cn/index.html) 作为服务和配置中心， [Gateway](https://spring.io/projects/spring-cloud-gateway) 作为统一网关， [Security](https://spring.io/projects/spring-cloud-security) 进行认证和授权，使用 [Maven](https://maven.apache.org/) 构建项目。

## MySQL

[MySQL](https://www.mysql.com/) 是最流行的关系型数据库管理系统之一。

## Mybatis-Plus

[MyBatis-Plus](https://www.baomidou.com/) (opens new window)（简称 MP）是一个 MyBatis (opens new window)的增强工具，在 MyBatis 的基础上只做增强不做改变，为简化开发、提高效率而生。

# 部署

## Docker

网站所需的所有服务都在 [Docker](https://www.docker.com/) 容器中运行。

# 运维

## Jenkins

使用 [Jenkins](https://www.jenkins.io/) 实现DevOps，通过拉取git服务器代码完成项目构建及部署。配置git webhook实现提交代码后自动更新、部署项目，实现自动化。
