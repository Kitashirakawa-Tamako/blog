# 二级域名
二级域名是在顶级域名下的一个子域名，即在主域名之前的部分。例如，在网址www.example.com中，"www"就是二级域名。二级域名通常用于将网站分为不同的部分或子网站，方便管理和访问。例如，一个公司可能使用二级域名来区分其不同的产品或服务，如product1.example.com和product2.example.com。

我网站的一级域名为jianghaoyu.world，我准备分配一个二级域名admin.jianghaoyu.world去代理原来的后台管理系统。
# 域名解析
添加一条A记录类型，将admin.jianghaoyu.world指向原来的ip。![微信截图_20240112145835.png](/image/bb275cc5-6ee1-4ec9-8a79-f1c9c5675325.png)

添加完成后使用ping命令测试，确保域名能正确指向我们的ip地址。

# nginx配置
打开Nginx的配置文件，通常位于/etc/nginx/nginx.conf。
在http块中，添加一个新的server块来配置二级域名。

```
server {
    listen 80;
    server_name admin.jianghaoyu.world;
    root /var/www/html;
    index index.html index.htm index.nginx-debian.html;
    location / {	
        proxy_pass http://localhost:3001;
        proxy_http_version 1.1;
	proxy_set_header Upgrade $http_upgrade;
	proxy_set_header Connection 'upgrade';
	proxy_set_header Host $host;
	proxy_cache_bypass $http_upgrade;
    }
}	
```
